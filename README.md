# 📝 Notes App

A modern and responsive Notes application built with **Flutter**, designed to demonstrate clean architecture principles and local data persistence. The app provides a smooth user experience for creating, editing, deleting, and organizing notes efficiently.

## ✨ Features

* Create, edit, and delete notes.
* Local data storage for offline access.
* Clean and responsive UI.
* Simple and intuitive user experience.
* Well-structured and maintainable Flutter code.

## 🛠️ Tech Stack

* Flutter
* Dart
* Local Storage (Hive)
* State Management (Bloc/Cubit)

## 🎯 Purpose

This project was developed to strengthen Flutter development skills, focusing on clean code practices, reusable widgets, state management, and local database integration.

Contributions, suggestions, and feedback are always welcome!
